Networking Glossary

Key terms in plain language.

Bandwidth
The maximum amount of data that can be sent over a connection in a given time, usually measured in Mbps or Gbps.
DHCP
Dynamic Host Configuration Protocol. Automatically assigns IP addresses to devices when they join a network.
DNS
Domain Name System. Translates human-friendly names like example.com into IP addresses.
Ethernet
The most common wired networking standard for local area networks.
Firewall
Hardware or software that allows or blocks network traffic based on security rules.
Gateway
A device, usually a router, that connects a local network to other networks such as the internet.
HTTP / HTTPS
The protocols used to load web pages. HTTPS adds encryption to protect the data.
IP Address
A numeric label that identifies a device on a network.
LAN
Local Area Network. A network that covers a small area such as a home, school, or office.
Latency
The delay between sending data and it arriving. Lower is better.
MAC Address
A unique hardware identifier assigned to a network interface. Used by switches at Layer 2.
NAT
Network Address Translation. Lets many private devices share one public IP address.
Packet
A small unit of data sent across a network, containing a header and a payload.
Port
A number that identifies a specific service on a device (e.g., 80 for HTTP, 443 for HTTPS).
Protocol
A set of rules that define how devices communicate.
Router
A device that forwards data between different networks.
Subnet
A smaller network created by dividing a larger one, which improves organization and security.
Switch
A device that connects devices on the same network and forwards data using MAC addresses.
TCP
Transmission Control Protocol. Provides reliable, ordered delivery of data.
UDP
User Datagram Protocol. A faster but less reliable protocol, used for streaming and gaming.
VPN
Virtual Private Network. Creates an encrypted tunnel for your traffic over an untrusted network.
WAN
Wide Area Network. A network spanning a large area; the internet is the largest WAN.
Wi-Fi
Wireless networking technology that connects devices to a network using radio waves.
